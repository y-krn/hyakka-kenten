# 百科拳典の UI の決まり

画面を作る・直すときは、この決まりに合わせる。スマホの幅で見て確かめる。

## 0. いちばん大事なこと：そろえる

- ボタンの見た目は、下の3段階のクラス（`btn big`・`btn`・`btn small`）だけで決める。画面ごとに文字の大きさ・高さ・余白を足したり変えたりしない。
- 新しい画面を作るときも、既にある画面と同じ部品・同じ並べ方を使う。迷ったら既にある画面に合わせる。
- 決まりに合わない所を見つけたら、その場で直す。

## 1. ボタンは3段階だけ

| 段階 | 見た目（クラス） | 使う場面 |
|---|---|---|
| 主 | 黒く塗った大きいボタン（`btn big`） | その画面でいちばんしてほしいこと（対戦開始、ダンジョンの入口、結果を共有など）。1つのカード・画面に1つまで |
| 副 | 枠だけのボタン（`btn`） | 主と並ぶ選択肢、または対等な選択肢どうし |
| 補助 | 小さいボタン（`btn small`）か文字のリンク | 観戦・閉じる・引き返す・入力を消すなど、脇役の操作 |

## 2. 並べ方

- 補助のボタンは、主・副と同じ行に置かない。別の行にまとめる。
- 主と副を同じ行に並べるときは、高さをそろえる。
- 対等な選択肢（「このまま進む」と「乗り換えて進む」など）は、同じ見た目・同じ幅にする。2つなら横に半分ずつ。3つ以上か文言が長いときは、縦に積んで幅いっぱいにする。
- 主のボタンが1つだけの画面では、幅いっぱいにしてよい（幅だけを変え、大きさは変えない）。

## 3. 文言

- 動詞で短く。8文字程度まで（「進む」「観戦」「結果を共有」）。
- 記事名のように長くなるものはボタンに入れず、上の表示に出す。
  - 悪い例：「🔁 ツギクル芸人グランプリになって進む」
  - 良い例：上に「ツギクル芸人グランプリに勝った」と出し、ボタンは「乗り換えて進む」
- スマホとパソコンで動きが違うときは、文言も合わせる（スマホは「結果を共有」、パソコンは「結果をコピー」）。

## 4. 説明に頼らない

- 見れば分かる画面にする。説明文は1行まで。決まりごとを長々と書かない。
- 数値の能力（HP・攻撃・防御・速さ）は画面に出さない。強さは記事の事実から読ませる。

## 5. 確かめ方

- スマホの幅（375px）で、ボタンの大きさ・並び・折り返しを見る。
- 同じ段階のボタンが、画面をまたいで同じ大きさに見えるかを確かめる。
